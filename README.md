# Dados experimentais — Sobre sistemas de congruência lineares

Este repositório contém a planilha `2a-Pasta.xlsx`, com os dados experimentais utilizados no artigo *Sobre sistemas de congruência lineares*.

A planilha reúne 200 testes computacionais para cada tamanho de chave (1024, 2048 e 4096 bits), comparando os tempos de decodificação RSA por método direto e via Teorema do Resto Chinês (TRC).

O código utilizado nos experimentos está disponível no Apêndice A do artigo.
